# Customer Health AI 🚦

##  Descripción
Prototipo de agente de IA para detectar clientes en riesgo usando métricas básicas.
##  Objetivo
Identificar clientes en riesgo antes de que presenten inconformidad.
##  Métricas utilizadas
- Nivel de servicio
- Puntualidad
- NPS
- Quejas abiertas
## Lógica
Se usa un sistema de reglas simples para clasificar:
- 🟢 Bajo riesgo
- 🟡 Riesgo medio
- 🔴 Alto riesgo
## Funcionalidades
- Captura de datos simulados
- Evaluación automática
- Recomendaciones preventivas
## Beneficios
- Reducción de churn
- Mejora en atención proactiva
- Priorización de clientes
## Limitaciones
- No usa datos reales
- Modelo basado en reglas simples
